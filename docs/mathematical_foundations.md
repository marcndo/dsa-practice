## Propositions and Connectives.

**Formal statement:** A proposition is a statement that is either true or false but not both. Examples of propositions include the following.
* 1 + 1 = 6.
* It would rain today.
* Tesla manufacture self driving cars.
Wherever, there're statements which are not propositions. Example.
* It's one o'clock(This can be true and false at the same time based on the timezone).
* Close the windows(a truth value can't be assigned to this)

Connective: They binds propositions together.
Examples of connectives include the following
Let p and q be two propositions
* Implication: p impliest q (p⟶q). This is true except when p is true but q false.
* Or: p or q (p⋁q). This is true whenever atleast of the proposition is true
* And: p and q (p⋀q). This is true only when both propositions are true.
